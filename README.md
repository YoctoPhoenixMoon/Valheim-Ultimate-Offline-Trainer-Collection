## 🔧 How It Works

The trainer modifies the game's memory while it is running using standard Windows API calls. It features:

- **In-memory modifications** — reads and modifies values in real-time
- **No external dependencies** — runs entirely as a standalone .exe
- **No game file modification** — all changes are applied in memory only
- **Apprentice safety** — patches restored on cheat disable, on detach, and on app quit

All modifications disappear when you close the trainer. Your game files remain untouched.
